# graphication-primitives-tracing

Simple Java Swing environment for graphication class practice tracing primitives on a canvas.

## Primitives included
- Point
- Line
- Circle
- Rectangle
- Oval
- Polygon
- Heart

## Run
```bash
mvn test
mvn exec:java -Dexec.mainClass=com.graphication.App
```

Controls:
- Select primitive in the top dropdown.
- Click for a point.
- Click and drag for all other primitives.
- Use **Clear** to reset the canvas.
